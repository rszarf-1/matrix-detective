# Matrix Detective

A browser game for Session 5 of *Redistribution Policy and Politics* (2026–27): students choose a country they know (Poland, Italy, Belgium, China or Mongolia, or a mixed deck), place real policies in Rodrik and Stantcheva's policy matrix (stage × income group), say who pays and how sure they are, and get feedback and a personal debrief.

**Play:** https://rszarf-1.github.io/matrix-detective/

## Use

Open the link in a modern browser, on a computer or a phone. No account or installation is needed. The game runs entirely in the browser and stores nothing. At the end, "Send to your teacher" opens the course Google Form with the student's result code filled in.

The warm-up links to the companion simulator, the [Toy Society Poverty Lab](https://rszarf-1.github.io/toy-society-poverty-lab/).

## Hosting and updates

GitHub Pages serves `index.html` from the root of the `main` branch. Commit changes to that file to update the live game. The card facts and their sources are documented in the course's instructor key, which is not part of this repository.
